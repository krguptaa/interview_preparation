# Interview Preparation

Welcome to the interview preparation repository. This repository contains interview questions and resources for various technologies and frameworks.

## Technologies

- [Angular](angular/README.md#angular) - Core Angular interview questions
- [AWS](aws/README.md#aws) - Amazon Web Services interview questions
- [Laravel](laravel/README.md#laravel) - Laravel framework interview questions
- [MySQL](mysql/README.md#mysql) - MySQL database interview questions
- [N8N](n8n/README.md#n8n) - N8N workflow automation interview questions
- [Node.js](nodejs/README.md#nodejs) - Node.js interview questions

## Structure

Each folder contains a dedicated README.md file with interview questions and answers for that specific technology. Click on any technology above to navigate to its respective interview questions.

## Usage

Browse through the folders to find interview questions relevant to the technology you are preparing for. Each README contains categorized questions with detailed answers and code examples.
